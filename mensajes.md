# Mensajes para las agencias

> Las URLs son las **previstas**: todavía no se subieron a Cloudflare (hace falta `npm run demos -- prospeccion/agencias.csv --deploy` con `wrangler login`).

## Guarischi Automotores

Demo: https://demo-guarischi-automotores.pages.dev

```
Hola, ¿cómo andan? Soy Santiago. Armé una maqueta de cómo podría verse el sitio web de Guarischi Automotores (Concepción del Uruguay): catálogo con filtros, ficha por unidad, comparador, financiación, horarios y botón de WhatsApp. Es una demo sin costo, con datos de ejemplo, para que la veas desde el celular:

https://demo-guarischi-automotores.pages.dev

Si te gusta, la adaptamos con su stock, sus fotos y sus datos reales. ¿Te la puedo mostrar en una llamada de 10 minutos? Si no te interesa, decime y no te molesto más.
```
